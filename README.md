# Geometry Java Layanglayang

Java-based geometry calculation program for calculating the area and perimeter of a kite (Layang-Layang) shape.

## Features
- Kite area calculation
- Kite perimeter calculation
- User input processing
- Geometry calculation system
- Simple console-based interface

## Technologies
- Java
- OOP Concept

## System Functions
- Input kite dimensions
- Calculate kite area
- Calculate kite perimeter
- Display calculation results

## Formula Used
### Area Formula
Area = (d1 × d2) / 2

### Perimeter Formula
Perimeter = 2 × (side_a + side_b)

## Concepts Used
- Object-Oriented Programming
- Geometry Calculation
- User Input Processing
- Mathematical Operations
